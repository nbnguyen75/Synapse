# Mandatory Skills & Simplification Rules

All development workflows and coding agents MUST continuously activate and apply the following core skills:

1. **`improve`**:
   - Continuously evaluate codebase design, cleanliness, DX, and alignment with modular monolith architecture.
   - Ensure explicit boundary compliance, clean error handling, and structured feature separation.
   - Follow plan numbering, lifecycle, and archiving rules in `.agents/rules/improve.md`.

2. **`ponytail`**:
   - Always deliver the simplest, most minimal, and most direct solution that works.
   - Strictly adhere to YAGNI (You Aren't Gonna Need It).
   - Prefer standard library, native language, and runtime capabilities over custom helpers or new third-party dependencies.
   - Eliminate speculative abstractions, wrapper objects, and premature generalizations.

3. **`ponytail-review` / `ponytail-preview`**:
   - Conduct mandatory anti-complexity and anti-bloat reviews on all proposed designs, code diffs, and implementations.
   - Proactively strip redundant code, superfluous boilerplate, and unneeded flexibility before concluding tasks.
